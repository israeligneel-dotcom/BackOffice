Proyecto Backoffice

Primer avance del proyecto final

Vistas incluidas

1. index.html: Pantalla principal de inicio de sesion con validacion de formulario y alertas interactivas,
2. register.html: Pantalla para crear usuario con la misma linea de diseño,
3. home.html: Vista inaccesible. Si intentas entrar directo a esta pagina, te redirige automaticamente al login

Librerias utilizadas
Google Fonts (fuentes Outfit y Rajdhani),
FontAwesome 6 (iconos en inputs y botones),
SweetAlert2 (mensajes de alerta en los formularios)
